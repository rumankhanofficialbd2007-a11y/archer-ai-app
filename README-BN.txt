ARCHER AI - Android ফোনে ইনস্টল করার নিয়ম

এটি একটি ইনস্টলযোগ্য PWA প্রোটোটাইপ।

১) এই ফোল্ডারের সব ফাইল একটি HTTPS ওয়েব হোস্টিংয়ে আপলোড করতে হবে (যেমন GitHub Pages বা Netlify)।
২) Android ফোনে Chrome দিয়ে সেই ওয়েব ঠিকানা খুলুন।
৩) Chrome-এর তিন ডট মেনু থেকে “Install app” অথবা “Add to Home screen” চাপুন।
৪) ARCHER AI ফোনের অ্যাপ আইকন থেকে চালু হবে।

যা কাজ করে:
- মোবাইল-উপযোগী ARCHER AI ইন্টারফেস
- সমর্থিত Chrome-এ speech recognition ও text-to-speech
- ক্যামেরা প্রিভিউ (অনুমতি প্রয়োজন)
- সমর্থিত ব্রাউজারে স্ক্রিন শেয়ার
- লোকাল মেমোরি (এই ডিভাইসের ব্রাউজারে সেভ হয়)
- অফলাইন অ্যাপ শেল

গুরুত্বপূর্ণ সীমাবদ্ধতা:
এটি এখনো আসল AI সার্ভারের সঙ্গে যুক্ত নয়। Chat বর্তমানে ডেমো উত্তর দেয়। সত্যিকারের ChatGPT-ধরনের উত্তর, ছবি বিশ্লেষণ, cloud memory ইত্যাদির জন্য একটি নিরাপদ backend/API সংযোগ করতে হবে। API key সরাসরি এই HTML ফাইলে রাখা নিরাপদ নয়।

এটি APK নয়; PWA হিসেবে ফোনে ইনস্টল হয়। APK বানাতে Android packaging/build পরিবেশ প্রয়োজন।
